# Claude·GPT 사용량 조율 규칙

이 문서와 `token-budget.ps1`, `token-budget.json`, `token-ledger.md`는 커밋하지 않는다.

## 사용량 확인

작업 시작 전, 작업 종료 후, 상대에게 넘기기 전에 작업본 루트에서 실행한다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File docs/validation/debate/token-budget.ps1
```

출력의 한 줄 요약만 읽는다. 전체 값은 `docs/validation/debate/token-budget.json`에 저장된다. 수치는 사용률(%)이며 남은 토큰 수가 아니다.

## 상태

| 상태 | 조건 | 할 수 있는 일 |
|---|---|---|
| normal | 세션 70% 미만, 주간 75% 미만 | 구현, 검증, 리뷰 |
| conserve | 세션 70% 이상 또는 주간 75% 이상 | 작은 범위의 리뷰와 답변만. 넓은 탐색, 새 워커, 장시간 실행 금지 |
| stop | 세션 85% 이상 또는 주간 90% 이상 | 현재 단계만 안전하게 정리하고 원장에 기록. 새 작업 금지 |
| unknown | 수치를 읽지 못했거나 60분 이상 오래됨 | conserve처럼 행동 |

## 역할

- `lead`로 표시된 쪽이 다음 작업을 맡는다. 이미 진행 중인 단계는 끝난 뒤에 넘긴다.
- 구현한 쪽이 자기 변경의 유일한 리뷰어가 되지 않는다. 상대가 `stop`이면 리뷰를 생략하지 말고 `리뷰 대기`로 기록한다.
- 같은 파일을 동시에 수정하지 않는다. 담당은 `decision.md`를 따른다.
- 둘 다 `stop`이면 원장에 상태를 남기고 멈춘 뒤 사용자에게 알린다.
- 초기화 후 상태가 바뀌면 다음 작업 경계에서 역할을 다시 정한다. 진행 중인 작업을 사용량만으로 중단하지 않는다.
- 사용량 제한을 우회하거나 계정을 바꾸지 않는다.

## 넘기기

`docs/validation/debate/token-ledger.md`에 한 항목을 추가하고, 상대에게는 그 항목을 읽으라고만 전달한다.

```text
## 시각 | 보낸 쪽 -> 받는 쪽
- 사용량: 스크립트 한 줄 요약
- 완료: 변경 파일, 실행한 검사와 결과
- 다음: 받는 쪽이 할 일 1개
- 미실행·위험: 없으면 없음
```

긴 로그와 코드를 메시지에 복사하지 않는다. 파일 경로와 줄 번호, 수치만 전달한다.

## 유지할 제약

`decision.md`의 보류 상태와 `gpt-claude-collab.md`의 금지 사항이 이 문서보다 우선한다. 사용량이 많이 남아 있어도 보류된 소스 수정, 설치, 커밋, 푸시, 배포를 시작하지 않는다.
