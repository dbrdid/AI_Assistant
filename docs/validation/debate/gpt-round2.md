# GPT 2라운드 응답

## 1. 상대 날짜 처리

- 동의. 앱 날짜를 기준으로 상대 날짜를 계산하고 대조하는 것이 frozen config와 B단계 재실행을 피하는 더 작은 수정이다.
- Claude의 재현은 중요한 반례다. appCommands.mjs 55-57은 요청에 명시된 ISO 날짜만 비교하며, 날짜 없는 요청의 모델 생성 날짜를 막지 않는다.
- 위험을 좁혀야 한다. 단순히 날짜가 요청에 없다는 이유만으로 모든 날짜 필드를 거부하면 날짜 기본값이 허용되는 명령까지 깨뜨릴 수 있다. 날짜 슬롯이 있는 명령에서만 상대 표현을 기준 시각으로 해석하고, 근거 없는 날짜는 차단한다.
- 최소 실험: 합성 기준 시각 고정, 상대 날짜·날짜 없는 요청·명시 날짜 각 1건의 잘못된 날짜 출력과 올바른 날짜 출력을 planCommand까지 재생해 승인 카드 차단 여부 확인.

## 2. 값 없는 명령 전반의 의도 대조

- 동의. 누락 값 문제는 c05/c07에 한정되지 않는다.
- 직접 코드상 commandGrammar의 appCommands.mjs 113은 블록 추가의 값을 선택 사항으로 만들고, 91은 추출한 field가 없으면 모델 명령을 그대로 반환한다. 명령 형식만 맞아도 요청 의도와 다른 무값 작업이 planCommand에 도달할 수 있다.
- Claude의 실험 요청에 열거된 각기 다른 작업을 모두 허용하는지 내가 직접 재실행하지는 않았다. 그 결과는 Claude가 보고한 재현으로 취급하며, 코드 경로는 위험을 뒷받침한다.
- 최소 실험: 값 포함 작업 요청별로 모델에 가능한 다른 무값 명령을 대입해 승인 카드 미생성 확인. 값 없는 요청은 작업 종류가 일치하고 명시적 무값 의도일 때만 통과시킨다.

## 3. 새 선별셋과 48문항

- 동의. 48문항은 보정·개발 이력이 있고 결함 c05/c07/c11/c31을 수정 근거로 사용했으므로 후보 선별 점수로 다시 쓰면 낙관 편향이 생긴다.
- 48문항은 고정 회귀셋으로만 사용하고, 수정 내용과 겹치지 않게 새 소규모 선별셋을 후보 평가 전에 동결한다. 문서의 개발용 측정만으로 후보 우열을 확정하지 않는다.
- 최소 실험: 선별셋 해시와 채점 규칙을 모델 응답 열람 전에 기록하고, 같은 S22 llama.rn 설정에서 grammar 적용 여부를 고정해 후보별 1회 실행한다. grammar off 비교가 필요하면 별도 조건으로 표기하며 통합 점수로 섞지 않는다.

## 4. 정답과 Codex 기준 응답

- 동의. 평가 정답은 모델 응답이 아니라 검토 가능한 기대 명령과 승인 후 기대 상태여야 한다.
- Codex 응답은 기대값 초안 작성 보조로는 쓸 수 있지만 권위 있는 정답으로 간주하지 않는다. 독립 검토 후 문항 입력·기대 상태·채점 규칙을 동결하고 해시를 남긴다.
- 앱 규칙 라우터가 처리한 사례와 모델 경로 사례는 분리 집계한다. 고정 기준 시각은 상대 날짜 문항의 평가 설정으로 모델 입력에 포함시키고 양 모델에 동일하게 적용한다.
- 최소 실험: 동결한 합성 사례에서 허용되는 명령 및 저장 상태를 사람이 검토하고, 기대 데이터가 실제 모델 입력에 포함되지 않는지 실행 로그로 확인한다.
