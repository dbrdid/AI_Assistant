# 코드 작업: AI 연결 탭을 설정 전용으로 바꾸기

작은 범위의 작업이다. ponytail full을 유지하고, 이 파일은 커밋하지 않는다.

## 사용자 요청

AI 탭의 `AI 연결` 화면에서 `AI에게 요청` 입력창(`질문이나 앱 작업을 입력하세요…`)을 없앤다. AI 요청은 문서 블록을 길게 누르거나 블록 메뉴의 `AI에게 요청`으로만 시작한다.

## 수정

- `LocalModelScreen.js`가 대상 블록(`route.params.block`)이나 `commandRequest` 없이 열리면 연결 설정만 보여 준다.
  - 숨김: 요청 입력창, 전송 동의 체크, `보내기`·`중지` 버튼, 답변 영역
  - 유지: AI 연결 선택, 기기 모델 다운로드와 선택, 서버 주소와 모델, API 키, 안내 문구
- 설정 화면에서는 안내 문구를 "문서 블록을 길게 누르면 여기서 고른 AI에게 요청합니다." 정도로 짧게 바꾼다.
- 대상 블록이나 `commandRequest`가 있을 때의 동작은 그대로 둔다.
- 설정 전용 화면에 입력창이 없는지 확인하는 테스트를 추가하거나, 화면 테스트가 어렵다면 조건 함수를 분리해 검사한다.

## 완료 조건

- `npm run -s test:integration`이 통과한다.
- 원장에 한 줄을 남기고 멈춘다. 커밋과 푸시는 하지 않는다.
