# 결함 수정: 블록 대상 요청이 검토에서 거부됨

작은 범위의 수정이다. 절약 모드에서 진행해도 된다. ponytail full을 유지하고, 이 파일은 커밋하지 않는다.

## 재현 (웹 미리보기, 2026-11-24 Claude 확인)

1. 블록이 3개인 문서에서 2번 블록 메뉴의 `AI에게 요청`을 누른다.
2. `1분기 예산 초안으로 수정해줘`를 보낸다.
3. 규칙 해석 결과로 `2번 블록을 1분기 예산 초안로 수정`이 나온다.
4. 앱 작업 검토에서 `요청한 작업 또는 블록 내용과 해석 결과가 다릅니다`가 뜨고 저장되지 않는다.

## 원인

`LocalModelScreen.js` 132행이 `originalRequest`로 47행의 `request`(대상 줄 + 입력)를 넘긴다. `verifyModelCommand`는 이 형태를 거부한다. 같은 명령이라도 `originalRequest`를 `2번 블록 1분기 예산 초안으로 수정해줘`로 넘기면 통과한다.

## 수정

- 대상 블록이 있으면 검토 화면에 넘기는 `originalRequest`는 `(target.index + 1) + '번 블록 ' + prompt`로 한다.
- AI에 보내는 요청의 대상 줄은 그대로 둔다.
- 이 경우를 잡는 테스트를 추가하고 `npm run -s test:integration`을 다시 돌린다.
- 원장에 한 줄을 남긴다.
