# Qwen3.5-4B 모바일 앱 검증 기록

소스 기준은 `dbrdid/AI_Assistant`의 `SJW1212/improve-notion-style-app` 브랜치, 커밋 `8c5c099`다. Orca Run은 `run_005c12950703`이다.

## 한국어 기준응답 비교

Codex가 작성한 합성 한국어 사례 13개에 대해 Windows PC에서 Q4_K_M과 Q5_K_M을 기본·보완 프롬프트로 각각 실행했다. 총 52개 응답이 모두 JSON 스키마 검사를 통과했다. 의미와 필드 조건까지 충족한 사례는 두 모델 모두 7개에서 10개로 늘었다. 동일한 개발셋을 다시 측정한 수치다. 입력·기대 상태, 응답 원문, 모델 식별자, 실행 조건 및 논문·적용 사례는 [평가 보고서](../../ai/eval/README.md)에 있다.

실제 앱 검증기와 서비스에 응답을 재생했을 때 Q4는 15시 낭독회를 종일 일정으로 처리해 시간을 잃었고 Q5는 15시를 보존했다. 검색 전 파일 부재 단정, 원문에 없는 검색 기간 추가, 인용문의 숫자·단위 공백 변형도 발견했다. 승인 전 상태와 저장 후 값을 검증해야 하는 이유다.
