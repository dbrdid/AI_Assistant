# 서버 구현 검증 기록

## 실행 결과

| 검사 | 결과 | 범위 |
| --- | --- | --- |
| npm test | 24/24 통과 | Node.js 26.13.0 / Windows, 모의 추론 제공자 및 실제 loopback HTTP |
| node --check | 통과 | src/scripts/test JavaScript 전체 |
| npm install 의존성 감사 | 알려진 취약점 0건 보고 | 설치 시점 Fastify 5.12.8, Ajv 8.20.0 및 잠금 파일 의존성 |

24개 시험은 설정 누락·토큰 누락/위조/만료, 승인 선언·타입·추가 필드·입력 크기, 시간대·불가능한 날짜, 모델 JSON·후보 출처·인용 ID/revision/발췌, 근거 없음, 사용자별 요청량·동시성, 전체 동시성, 타임아웃·연결 중단·슬롯 해제, 내부 오류 비노출과 Ollama 요청/응답 전송을 포함한다.

초기 제한 환경에서는 loopback 연결이 EACCES로 차단되어 HTTP 시험 1건이 실패했다. 로컬 네트워크 접근을 허용한 뒤 같은 시험이 통과했고, 연결 중단 등 추가 회귀 시험까지 포함한 최종 24개를 재실행해 통과했다.

## 미검증

실제 Ollama 모델의 추론·한국어 품질·날짜/의미 정확도, GPU/RAM/비용/처리량, Node.js 24 실행, Docker 이미지 빌드/Compose 실행, HTTPS 프록시·인터넷 배포, React Native 실기기 연결, 정식 계정 인증은 미검증이다. Docker CLI가 없는 환경이므로 컨테이너 실행은 통과했다고 주장하지 않는다. Node.js 24는 설정한 지원 하한이며 이번 로컬 시험 버전은 26.13.0이다.

현재 모델은 환경 변수로 선택하므로 서버 시작 전에 운영자가 대상 런타임에서 설치·호환성을 검증해야 한다. 모의 서버 통과는 실제 모델 연결·제품 수용을 뜻하지 않는다.
