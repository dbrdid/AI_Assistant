# ADR 0001 — 모바일 LLM 추론을 별도 AI 서버로 이동

- 결정일: 2026-11-08
- 상태: 사용자 요청에 따라 설계 방향 채택 / 구현·배포 미완료

## 배경

기존 설계는 기기 내 LLM 우선과 필요 시 외부 보완이었습니다. 사용자가 모바일에서의 모델 실행 부담을 고려해 별도 서버 구축으로 변경했습니다. 특정 기기·모델의 실행 불가능을 측정으로 확정한 결정은 아닙니다.

## 결정

모바일은 UI·로컬 기록·검색·AI 전송 허용·결과 검증·승인을 담당합니다. 생성형 AI 추론은 별도로 구축하는 서버에서 실행합니다. 앱에는 서버 호출 Provider를 연결하고 기본 경로에서 모델 다운로드·로딩·기기 내 추론을 요구하지 않습니다.

기존 외부 보완 정책 중 전송 금지·유효한 범위 허용·인증·예산·취소/최신성 검사는 서버 AI의 기본 호출 관문으로 이어갑니다. 기기 내 추론을 먼저 시도하는 단계만 제거합니다. 서버 AI 사용을 거절하면 AI를 실행하지 않으며 수동 기능을 제공합니다.

## 유지하는 범위

제품 기능·현재 UI 방향·로컬 SQLite 정본·원문/출처·승인 트랜잭션·revision·단계적 개발·계정/동기화 분리를 유지합니다. 모델이 DB나 외부 도구를 직접 실행하지 못하게 하는 경계도 유지합니다.

## 영향과 미정

AI에는 네트워크·서버 가용성·운영 비용이 필요하고 기록 일부가 기기 밖에서 처리됩니다. 인증·전송 범위·보관 정책·서버 자원·한국어 품질을 실제 시험해야 합니다. 서버 프레임워크·모델·런타임·호스팅·운영 주체·제3자 API 사용 여부는 미정입니다.

동기화 서버 구축·전체 기록 업로드·UI 재설계·모바일에 대한 실행 불가능 판정은 이 결정에서 추가하지 않습니다.

## 설계 기준과 우선순위

현재 앱의 전체 아키텍처 v1.26, M1 기능 설계 v1.7, AI 분석·검색·기억 설계 v1.19, 단계별 DB 확장 설계 v1.16, 인터페이스 상세 설계 v1.1의 골자를 사용했습니다. 원문에 남은 로컬 우선 설명과 충돌하면 **AI 실행 위치에 한해 이 결정과 이 저장소의 서버 추론 흐름을 우선**합니다. 과거 검증 기록은 서버 경로 검증으로 승계하지 않습니다.
