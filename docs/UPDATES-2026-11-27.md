# Atria 변경·개선 정리 (0.0.5 이후 ~ 2026-11-27)

작성일: 2026-11-27. 기준 브랜치: `worktree-block-renderer-registry`, 기준 커밋: `cdad55c`.
범위: 0.0.5 릴리스(`304cf72`) 이후의 모든 변경. 0.0.6·0.0.7은 릴리스됐고, 0.0.7 이후 커밋은 아직 `main`에 올리지 않았다.

## 2. 탐색·공통 화면

- **상단 탭 고르기:** 화면을 길게 누르면 지금 탭에 테두리가 켜진다. 누른 채 좌우로 밀면 테두리가 손가락을 따라 옮겨지고, 손을 떼면 그 탭으로 이동한다. 예전의 옆 세로 메뉴는 없앴다. (`54da588`, `68d62ec`, 첫 사용 안내 문구도 맞춤)
- **AI 아이콘:** 십자성 모양을 펼친 책 모양(`AtriaBook`과 같은 모양)으로 바꿨다. 공용 아이콘을 바꿔 AI 질문 막대, 블록 AI, 설정, 브리핑, 알림, 도구 메뉴 15곳에 한꺼번에 적용됐다. (`31c16e2`)
- **AI 책 아이콘 애니메이션:** 평소엔 천천히, 답을 만드는 중엔 빠르게 장이 넘어간다. (`d3b94a5`)
- **색 점 제거:** 공간·그룹·AI 표시 앞의 색 점을 없앴다. 팀 공간 구분은 프로필 아래 배지와 테두리로 한다. (`0e4739c`)
- **키보드:** 입력 칸이 있는 아래 시트(문서 AI 요청 등)와 오늘 입력줄이 키보드 위로 올라온다. (`6188903`, `36da104`, `d6b8ef2`)
- **설정 화면:** 프로필 메뉴의 설정 화면들을 Notion 스타일의 평평한 행으로 바꿨다. (`c514f2d`)
- **첫 사용 안내:** 오늘과 AI 채팅에 한 번만 보이는 안내를 추가했다. (`74196f8`)
- **설명 문구 정리:** 꼭 필요하지 않은 설명을 지웠다. 대상은 블록 AI 안내와 요청 예시, 녹음 창의 "외부 AI로 보내…" 설명, 파일 보관함 안내, 채팅·설정·처음 설정 화면의 부가 설명이다. 외부 전송 고지와 오류 해결 안내는 남겼다. (`98647ac`)
- **선택 표시 통일:** 하위 탭 줄 아래의 선택 항목은 문서 목록 "모든 문서 / 즐겨찾기"와 같은 모양이다(글자 12, 높이 44, 간격 20). 고른 항목은 굵은 글자로만 표시한다. 대상은 문서 거르기, 작업 검토 탭, 빠른 입력, 파일 보관함, 검색 거르기, 할 일 "내 담당", 공용 칩이다. (`dd12aa7`)

## 3. 홈·업무·캘린더

- **오늘 하단:** 오늘 화면도 다른 탭과 같은 공통 하단(검색, AI에게 질문하기, 새로 만들기)을 쓴다. 메모와 파일은 '빠른 입력'에서 넣는다. (`98647ac`)
- **AI 노트:** 새로 만들기 > AI 노트를 누르면 오늘로 이동하지 않고 지금 탭에서 바로 녹음한다. 녹음 중에는 하단에 녹음 막대가 보인다. (`useNoteRecorder`)
- **공간 선택:** "모두"와 개인·팀 선택을 하나로 합쳤다. 목록 하나에서 모든 공간, 개인, 팀을 고른다. 캘린더, 할 일, 예전 메모 목록에 적용된다. (`dd12aa7`)
- **캘린더 중간 막대:** 달력을 크게 펼친 상태에서 위로 올리면 패널이 손가락을 따라오고, 끝까지 올리면 달력이 접힌다. 크게 펼친 상태에서 다시 내리면 제자리로 돌아온다. 달력 스크롤이 끌기를 가로채던 문제를 막았다. (`98647ac`, `9656e31`)
- **필터 정리:** 할 일 필터는 목록에서 고르고, 문서 목록은 하나로 합쳤으며, 작업 검토는 화면 안에서 처리한다. (`97ff5c4`)

## 4. 문서·블록 편집

- **문서 줄 메뉴:** 문서 목록의 `>` 왼쪽에 `…`이 생겼다. 즐겨찾기, 하위 문서 추가, 휴지통으로 이동(확인 창과 되돌리기)을 고를 수 있다. 지운 문서의 하위 문서는 한 단계 위로 옮겨 보존한다. 보기 권한만 있으면 삭제와 즐겨찾기는 숨긴다.
- **블록 손잡이:** 왼쪽 ⠿ 손잡이는 선택한 블록에만 보인다. 선택되지 않은 빈 블록에는 흐린 "빈 블록" 글자가 보인다. (`98647ac`, `a6310de`)
- **보기 권한 그룹:** 공개 그룹에서 '보기' 권한만 있는 문서와 할 일은 읽기 전용으로 열린다. 권한을 확인하기 전에도 읽기 전용으로 둔다. (`9fbed98`, `cd1f13e`, `9656e31`)

## 5. 녹음·카메라·파일

- 녹음은 휴대폰 `Recordings/Atria` 폴더에 저장한다. (`71913e3`)
- Notion 스타일 녹음 막대를 추가했다(실시간 음량, 일시정지, 끝내기). (`c9e7b0e`)
- 휴대폰 기본 카메라처럼 전체 화면 카메라로 바꿨다. (`f8b517c`)
- 녹음 파일을 지울 수 없을 때(재설치 등)도 목록에서는 뺀다. 목록 저장에 실패하면 방금 만든 파일을 정리한다. (`cd1f13e`)

## 6. AI

### 키와 연결
- **AI 키 기억:** 내 서버, OpenAI, Anthropic 키를 휴대폰 보안 저장소(`expo-secure-store`, Android Keystore)에 기억한다. 로그아웃하면 지운다. "기억한 키 지우기"는 그 공급자 키만 지운다. 키는 순서대로 저장해, 입력하다 만 키가 남지 않는다. (`0d1333d`, `cd1f13e`)
- **집 밖에서 내 PC AI:** 같은 와이파이 밖에서도 브리지에 닿도록 암호화 중계를 넣었다(Supabase 실시간 채널, AES-256-GCM). 중계는 브리지 연결에만 쓴다. 일반 서버는 바로 연결해 실제 오류를 보여 준다. 예전에 저장한 브리지 연결도 브리지로 인식한다. (`665b94a`, `cd1f13e`, `9656e31`)
- **이 기기 모델:** 휴대폰 밖으로 보내지 않으므로 전송 동의를 묻지 않는다.

### 앱 작업 (AI가 제안하고 사용자가 승인)
- **여러 작업:** 한 요청에서 여러 작업을 순서대로 제안하고 하나씩 승인한다. 작업마다 원래 요청의 해당 부분과 대조한다. (`1f007b6`, `31b1aa3`)
- **새 작업 10종** (`853faf4`, `itemCommands.mjs`):
  - 할 일·일정 완료와 완료 취소, 삭제, 이름 변경, 날짜·시간 변경, 우선순위 변경, 알림 변경
  - 블록 종류 바꾸기(문단·제목·목록·체크)
  - 표에 행·열 추가
- **안전장치:**
  - 모델 명령은 사용자가 말한 값만 쓸 수 있다. 날짜는 "12월 3일 오후 4시" 같은 표현도 알아듣는다.
  - 요청한 동작과 다른 명령은 거절한다.
  - 대상은 하나로 정확히 특정돼야 한다.
  - 승인은 한 번만 실행된다.
  - 검토 뒤 문서가 바뀌면 실행하지 않는다.
- **해시 고정:** `appCommands.mjs`는 S22 평가 때문에 해시가 고정돼 있어 수정하지 않았다. 새 작업은 별도 모듈에 넣었다.

### 블록 AI
- **답과 질문 구분:** 블록에서 부르는 AI도 앱 작업을 제안할 수 있고, 블록 글을 근거 값으로 쓴다. AI가 값을 되물을 때는 "AI 질문"으로만 보이고 문서에 들어가지 않는다. (`a6310de`)
- **규칙 해석:** "체크로 바꿔줘", "행 추가"처럼 분명한 요청은 AI 없이 바로 명령이 된다. 기존 규칙이 "이 블록을 X로 변경"을 글 수정으로 잘못 읽던 경우는 버린다.
- **승인 위치:** 블록이 아닌 작업(할 일·일정·프로젝트 등)은 다른 화면으로 가지 않고 AI 창 안에서 승인·취소한다. (`93d2f25`)
- **문서 안 제안:** 블록을 바꾸는 작업은 바로 저장하지 않고 문서 안에 강조된 제안으로 넣어, 문서에서 수용·거절한다. AI 창은 닫힌다. (`cdad55c`)
  - 커밋 전 정리: 제안 표시는 흰 테두리만 쓰고, 안내 문구와 "AI 제안 N개" 막대는 없앴다. 삭제 제안의 버튼은 "삭제 / 유지"다.

## 7. 공간·팀·프로젝트

- **프로젝트 그룹:** 그룹마다 보기, 편집, 관리 권한을 두고 문서·할 일의 공개 범위를 정한다. 서버(RLS·트리거)가 권한을 강제한다. (`4b96cf9`)
- **초대:** 공간 초대 코드와 프로젝트 링크 초대 하나를 1, 5, 10, 50명이 쓸 수 있다. (`d1ee39c`, `d3e53e4`)
- **팀 공간:** 팀 공간은 겉모양이 다르고, 공간을 바꿀 때 한 번 묻는다. (`0494628`)
- **그룹 삭제:** 삭제 뒤 창이 다시 열리던 문제를 고쳤다. (`cd1f13e`)

## 9. PC 브리지 (보류 중)

- **계정 로그인:** 브리지를 Atria 계정에 로그인하면 같은 계정 앱이 자동으로 연결된다. 운영 마이그레이션은 보류 중이라 앱에서는 서버가 지원할 때만 보인다. (`decfba9`)
- **수정:** `--host` 주소로 중계를 전달하고, 로그인 중 네트워크가 잠깐 끊겨도 계속 기다리며, 계정 브리지 키를 캐시한다. (`9fbed98`, `9656e31`)

## 10. 코드 검토와 정리

- **세 차례 코드 검토:** 0.0.5 이후, 0.0.7 이후, 전체 작동을 검토했다. 확인된 문제는 모두 고쳤다. (`9fbed98`, `cd1f13e`, `9656e31`, `71db01b`)
- **안 쓰는 코드 삭제:** 채팅 아이콘 8개, 초대 횟수 함수 3개, `serverRoute`, 안 쓰는 import와 스타일을 지웠다. (`90e7b51`)
- **남긴 검토 항목:** 화면 낭독기 사용자의 블록 손잡이 접근이 있다. 지금은 선택한 블록에만 손잡이가 있다.

## 11. 되돌린 것

- 버튼 배경 없애기(`2e11499`)와 선택 강조 굵게(`8a91df1`)는 사용자 요청으로 되돌렸다(`5a14a33`, `3a3beec`). 그 뒤 선택 표시는 7번 항목(`dd12aa7`) 방식으로 다시 정했다.

## 12. 남은 일·결정 대기

- **`main` 반영과 0.0.8 릴리스:** 0.0.7 이후 커밋이 아직 로컬에만 있다.
- **보안 마이그레이션 운영 적용:** `20261126170000` 적용 승인이 필요하다.
- **블록 변경 제안 방식:** 사본을 따로 보여 주지 않고, 원래 블록 자리에서 바뀐 모습을 강조해 적용·되돌리기를 고르게 바꾼다. 작업 중이다.
- **보류:** 브리지 계정 로그인, 키 기기별 암호화(X25519), QR 키 입력, 캘린더 고도화(#9).
- **UI 후보:** 프로젝트 탭 제목 줄, 목록과 편집기의 문서 제목 불일치("Test"와 "제목 없는 문서"), 빠른 입력의 "저장" 위치.
