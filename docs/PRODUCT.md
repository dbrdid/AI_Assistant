# 제품 기능과 범위

## 목표

입력 → 기록 저장 → AI 정리 초안 → 사용자 검토 → 메모·할 일·일정 반영 → 기록 검색·출처 답변 흐름을 제공합니다. AI는 후보를 제시하고, 날짜·권한·데이터 변경의 최종 판단은 앱 서비스가 담당합니다.

## 첫 구현 범위

| 기능 | 동작 |
| --- | --- |
| 메모 | 텍스트 작성·수정·조회, 원문과 정리 초안 구분 |
| 할 일·일정 | 직접 입력, 날짜 검증, 목록·상태 관리 |
| 기본 검색 | 로컬 기록 조회·키워드 검색·삭제 필터 |
| 새 입력 정리 | 사용자가 허용한 텍스트를 서버에 보내 정리 초안·업무 후보 받기 |
| 검토·승인 | 후보 수정·거절·승인, 승인된 변경만 로컬 트랜잭션으로 반영 |
| 기록 질문 | 조건 해석 → 허용된 로컬 기록 검색 → 선택 근거로 서버 답변 생성 |
| 최소 비서 동작 | 허용된 로컬 조회·화면 이동과 출처 답변 |

기존 P0는 첫 구현 순서이며 전체 제품 목표의 축소가 아닙니다. 프로젝트·블록과 다양한 보기·미디어/회의·기억·의미 검색·협업/동기화·도구 실행은 전체 목표에 유지하고 단계별로 구현합니다.

## 유지하는 원칙

- 기본 기록은 모바일의 SQLite를 정본으로 관리합니다.
- AI 응답은 확정 데이터가 아닌 초안입니다.
- 기록 변경·일정 생성·외부 쓰기는 필요한 사용자 승인 뒤 수행합니다.
- 원문·출처·내용 버전을 보존하고 오래된 AI 결과의 반영을 차단합니다.
- AI 미동의·오프라인·서버 장애가 수동 기록을 막지 않습니다.
- 기존 UI 방향은 유지하며 이번 커밋에서는 화면을 재설계하지 않습니다.

## 모바일 지원

Android에서 첫 수직 기능을 검증하고 iOS를 이식·검증하는 기존 순서를 유지합니다. 설치형 데스크톱은 기존 확장 목표로 남기되 이번 모바일 골자 커밋에서 구현하지 않습니다. 출시일·스토어 승인·실기기 수용은 확정하지 않았습니다.
