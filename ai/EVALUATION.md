# 문서 AI 검증

2026-11-11. `npm --prefix ai test`에서 모의 제공자와 모의 HTTP 응답을 사용한 자동 시험 10개가 통과했다. 추가 패키지·네트워크·실제 Ollama·Gemma 모델은 사용하지 않았다.

시험 범위: 입력 제한·추가 필드 거절, 원문 인용 검사, 문서 ID/revision 보존, 호출 중 입력 변경 격리, 선행 취소, 기한 초과, 민감 오류 숨김, Ollama 요청 형식, HTTP 오류·잘못된 JSON·미완성·응답 크기 제한, 설정 URL 검증.

## 실제 모델 평가 계획

상태: NOT_RUN. Gemma 4 E2B 4비트를 우선 후보로 삼되 정확한 모델 파일·양자화·SHA256·Ollama 버전·하드웨어·프롬프트 버전·문맥 길이를 고정한다. 실제 모델 이름을 문서 예시의 임의 별칭으로 가정하지 않는다.

한국어 합성 문서 50개: 일반 메모 10, 회의록 10, 숫자·날짜 10, 부정·미확정 10, 명령 삽입·반복·입력 한계 10. 개선용과 최종 평가용을 분리한다. 원문에 없는 사실 생성, 중요한 내용 누락, 불확실성을 확정 표현으로 변경했는지 사람이 평가한다.

기록 항목: 유효 결과 수/전체 수, 사실 오류 수, 핵심 내용 보존율(문서별 사전 정답 항목 기준), 인용 정확도, 실패·타임아웃 수, 준비된 모델의 완료 지연 p50/p95, 콜드 스타트 지연, 시작·실행 최대 RAM. 기기 실행은 발열·배터리도 측정한다. 품질 목표와 허용 지연은 팀 합의 후 채택하며, 출력 형식 통과를 품질 통과로 간주하지 않는다.

긴 문서는 현재 거절하며 조용히 잘라서 요약하지 않는다. 원문 전송은 호출자 동의가 필요하다. 실제 사용자 개인정보와 모델 파일을 저장소에 넣지 않는다.

## 후속 검증

실제 Ollama 호환성, Gemma 한국어 요약 품질, 파일 텍스트 추출, 앱→AI→승인→SQLite 전체 경로, Fastify 연결, 동시 사용자와 Azure 운영은 아직 미검증이다. 기존 서버 24개 시험은 기존 API의 모의 모델 시험이며 이 문서 요약 모듈의 실모델 성능 증거가 아니다.

## 확장 검증 (2026-11-11)

확장 후 모의 모델 기반 시험은 총 23개 통과했다(기존 10개 + 신규 13개). 새 시험은 원문 전체 구간 커버리지·겹침·이모지 경계, 마지막 구간과 계층 병합, 길이별 실제 제한, 키워드 중복, 입력/질문 제한, 구간 인용과 병합 인용의 출처 제한, 모든 구간의 질문 처리, 근거 부족, 잘못된 인용·모순된 부족 플래그, 구간 사이 취소와 전체 기한 및 확장 Ollama 요청 형식을 검증한다.

실제 모델 상태는 계속 NOT_RUN이다. 기존 '긴 문서 거절' 설명은 summarizeDocument에 해당한다. 새 summarizeLongDocument/answerDocument는 최대 80000 단위이며 이를 넘으면 거절한다. 4000 단위 분할이 8192 토큰 내 입력 보장과 같다는 주장은 하지 않는다.

실모델 평가에는 다음을 추가한다: 구간 경계에 걸친 사실, 문서 앞뒤의 모순, 답이 마지막 구간에만 있는 질문, 여러 구간의 숫자를 함께 해석해야 하는 질문, 근거가 없는 질문, 원문 지시문 삽입, 긴 문서에서 정보 누락, 길이별 내용 보존 및 키워드 적절성. 합성 입력과 모의 결과를 한국어 모델 품질 측정으로 보고하지 않는다.
